# Internal Roadmap Pages

These routes stay available only from localhost until development is complete.
They should not be linked from the public hub or exposed on the public origin.

## `/heritage-risk`

- Target outcome: map-first review flow for cultural heritage and excavation risk.
- Expected inputs: site location or parcel context from the main 3D site workflow.
- Expected outputs: risk summary cards, map overlays, caution zones, and handoff context for the next planning step.
- Re-entry path later: reconnect with `/contour3dmodel` and downstream mass/planning review once the actual data workflow is implemented.

## `/max-mass`

- Target outcome: early-stage maximum mass study from parcel and regulation constraints.
- Expected inputs: parcel or parcel-group context, zoning summary, and review constraints.
- Expected outputs: regulation summary, candidate mass comparison, preview geometry, and 3D/CAD handoff.
- Re-entry path later: restore public exposure only after real generation logic and validation are complete.
