Roadmap Stage 8

문화재 발굴 위험도 지도

대지 주변의 문화재 조사 이력과 발굴 가능성을 지도 중심으로 읽는 기능을 위한 페이지입니다. 지금은 구조와 자리만 먼저 열어두고, 이후 위험도 레이어와 해석 카드, 관련 검토 흐름을 단계적으로 붙일 예정입니다.

페이지 주소
/heritage-risk
중심 인터페이스
지도 기반 레이어 탐색
현재 상태
준비 중인 확장 페이지

우선 붙을 흐름

  • 주소 또는 필지 기준으로 대상지를 지정합니다.
  • 문화재 관련 위험도 레이어를 지도에 겹쳐 확인합니다.
  • 검토 대상지를 중심으로 주의 구간과 해석 메모를 카드로 읽습니다.
  • 나중에는 대지·건물 3D 검토와 연동해 같은 프로젝트 흐름으로 이어갑니다.

예상 출력 방향

  • 위험도 등급 요약
  • 지도 레이어 캡처 또는 요약 리포트
  • 검토 메모와 확인 필요 항목
  • 후속 대지 검토 페이지로 넘어가는 handoff 정보

디자인 메모

대지모형 페이지보다 지도 비중을 더 높이고, 위험도 해석 카드와 상태 배지를 강하게 보여주는 방향이 잘 맞습니다. 즉시성보다 신뢰성과 해석 흐름이 더 중요합니다.

연동 메모

향후에는 같은 대지를 기준으로 /contour3dmodel과 연결하고, 나중의 /max-mass 페이지로 자연스럽게 이어지도록 프로젝트 공통 상태를 잡는 것이 좋습니다.

현재는 페이지 뼈대만 열어둔 상태입니다

이번 단계에서는 허브 구조와 라우트, 향후 기능을 담을 화면 틀을 먼저 마련했습니다. 실제 위험도 데이터와 지도 로직은 다음 구현 단계에서 붙이면 됩니다.
