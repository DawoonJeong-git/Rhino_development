Roadmap Stage 8

법규 기반 최대 매스 생성

대지 조건과 법규 해석을 바탕으로 초기 최대 매스를 검토하는 기능을 위한 페이지입니다. 지금은 실제 생성 로직을 넣기 전에, 기능이 들어올 자리와 흐름을 먼저 잡아둔 상태입니다.

페이지 주소
/max-mass
중심 인터페이스
규제 요약 + 매스 비교
현재 상태
준비 중인 확장 페이지

우선 붙을 흐름

  • 대지와 필지 그룹을 불러옵니다.
  • 법규 조건을 요약 카드로 정리합니다.
  • 조건에 맞는 초기 최대 매스를 생성합니다.
  • 여러 안을 비교하고, 필요 시 3D 대지모형과 교차 검토합니다.

예상 출력 방향

  • 규제 요약 카드
  • 최대 매스 미리보기
  • 안별 비교 패널
  • 그룹별 3D 또는 CAD handoff

디자인 메모

이 페이지는 지도만 보기보다 규제 해석과 안 비교가 중요하므로, 오른쪽에 분석 패널을 두고 중앙에는 대지와 매스를 크게 보여주는 방식이 잘 맞습니다.

연동 메모

다중 필지 선택, 필지 그룹 분리, 이후의 비교 기능과 잘 연결됩니다. 현재의 /contour3dmodel이 입력 페이지라면, /max-mass는 초기 설계 검토 페이지가 됩니다.

현재는 페이지 뼈대만 열어둔 상태입니다

이번 단계에서는 앞으로 붙을 최대 매스 기능의 전용 주소와 화면 틀을 먼저 만들었습니다. 실제 규제 해석과 생성 알고리즘은 다음 구현 단계에서 이어서 붙이면 됩니다.
